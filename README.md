# Number Guessing Game

A simple, interactive number guessing game written in Python using a Jupyter Notebook. It lets you pick a difficulty level and try to guess a randomly generated number while keeping track of your score.

## Features
* **3 Difficulty Modes:** Easy (1-50), Medium (1-100), and Hard (1-500) to change the number range.
* **Crash Proof:** Uses try/except blocks so the game doesn't break if you accidentally type a letter instead of a number.
* **Score Tracker:** Counts up and displays your total number of attempts once you get the right answer.

## How to Run
Make sure you have Jupyter installed, then run:
```bash
jupyter notebook guessing_game(1).ipynb
```
