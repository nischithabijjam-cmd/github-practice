#Number Guessing Game

A simple python number guessing game.

It randomly generates a number and the user has to guess it.
Based on difficulty level chosen, the range of numbers change.

##How to run
Make sure python is installed, then run:

python guessing_game.ipynb
 
##features

-Different difficulty levels to choose from.
-Tells if guess is too low or too high from the number.
-SHows number of attempts taken to guess.
